Anonymous Bootstrap

Lets a client with no key yet reach a small set of destinations (the site that sells one) through the tunnel anyway. Works by baking a single shared token into the client apps — every exit recognizes it locally (no arbiter round-trip) and, only for requests using it, restricts the destination to the list below. Same wire shape as a real user's session end to end, so there's nothing new for DPI to key on: the difference is a header value inside already-encrypted traffic, never visible on the wire.

Current token

This exact value must be embedded in every client build that wants to use the bootstrap path. It is a single secret shared by every install of the app — anyone who extracts it from the APK/binary can use it too, but only to reach the domains listed below, nothing else. Regenerating it silently breaks bootstrap access for every previously-built client the moment exits next refresh their cache (hourly) — only do this if a leak is suspected, or as routine hygiene timed to a new client release.
